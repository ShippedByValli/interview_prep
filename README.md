# Core Principles

## 1. Retrieval Over Storage
If a concept cannot be revised quickly before an interview, the note is poorly designed.

## 2. Compression Over Completeness
Prefer:
- frameworks
- heuristics
- one-page summaries
- interview articulation

Over:
- exhaustive theoretical notes.

## 3. Product Thinking First
Every technical concept should answer:
- Why does this matter?
- What business decision does it support?
- What assumptions matter?
- What can fail?

## 4. Experimentation Mindset
Strong emphasis on:
- trustworthy experimentation
- causal reasoning
- metric design
- ecosystem tradeoffs
- decision-making under uncertainty
